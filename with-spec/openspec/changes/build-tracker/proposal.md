# Proposal

## Why

Нужен автономный мини-трекер учебных задач на неделю без CDN, внешних библиотек и API-ключей, который прозрачно считает прогресс по часам и проходит единый набор автоматических проверок T1–T5.

## What Changes

- Создание мини-приложения трекера задач с файлами `index.html`, `styles.css`, `app.mjs`, `domain.mjs`, `tests/acceptance.test.mjs`.
- Реализация доменной модели задачи (`id`, `title`, `hours`, `done`) и стартового набора: «Чтение» — 2 ч, `done=true`; «Практика» — 4 ч, `done=false`; «Повторение» — 2 ч, `done=false`.
- Поддержка добавления, удаления и переключения статуса `done` с реальным изменением данных.
- Валидация формы: `title` после `trim` непустой; `hours` — число от 0.5 до 24 с шагом 0.5; пустое значение не равно нулю; ошибка показывается рядом с полем, данные формы сохраняются.
- Расчёт итогов: прогресс = округление(100 * сумма часов done / сумма часов всех задач); при отсутствии задач — 0% без `NaN/Infinity`.
- Фильтрация видимого списка (все/активные/выполненные) без влияния на итоговые часы и прогресс, считаемые по всем задачам.
- Адаптивный и доступный интерфейс: читаемость на ширине 390 px, без горизонтального скролла, подписанные поля и кнопки.
- Подготовка автоматических проверок T1–T5 на Node.js с нативными ES modules.

## Capabilities

### New Capabilities
- `tracker`: управление учебными задачами недели, валидация ввода, фильтрация списка, расчёт суммарных часов и прогресса, а также сценарии автоматических проверок T1–T5.

## Impact

- **Код (планируемый):** `index.html`, `styles.css`, `app.mjs`, `domain.mjs`, `tests/acceptance.test.mjs`.
- **Среда выполнения:** браузер для UI и Node.js для тестов, только нативные ES modules.
- **Зависимости:** без CDN, внешних библиотек и API-ключей.
- **Совместимость:** требования T1–T5 должны одинаково выполняться для предусмотренных реализаций в рамках задачи.
