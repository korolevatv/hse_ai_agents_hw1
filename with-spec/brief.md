Результат: автономный мини-трекер без CDN, внешних библиотек и API-ключей.

Цель: мини-трекер учебных задач на неделю.

Данные задачи:
- id
- title
- hours
- done

Стартовые задачи:
- Чтение — 2 часа, done=true
- Практика — 4 часа, done=false
- Повторение — 2 часа, done=false

Требования:

1. Добавление, удаление и переключение done реально меняют данные.

2. Название после trim непустое.
Часы — число от 0.5 до 24 с шагом 0.5.
Пустое значение не равно нулю.
Ошибка видна рядом с полем, данные формы сохраняются.

3. Прогресс = округление(100 * сумма часов done / сумма часов всех задач).
Если задач нет — 0%, без NaN/Infinity.

4. Фильтр влияет только на видимый список.
Итоговые часы и прогресс считаются по всем задачам.

5. При старте:
Всего 8 часов.
Выполнено 2 часа.
Прогресс 25%.

Если отметить «Практику» готовой:
Выполнено 6 из 8 часов.
Прогресс 75%.

6. Интерфейс читаем на ширине 390 px.
Без горизонтального скролла.
Поля и кнопки подписаны.

Автоматические проверки:
T1 — исходный пример: 8 часов, 2 выполнено, 25%.
T2 — отметить Практику: 6 из 8 часов, 75%.
T3 — фильтр активных не меняет общий прогресс.
T4 — проверка пустого названия и некорректных часов.
T5 — удаление всех задач: 0 часов, 0%.

Обе реализации должны проходить одинаковые проверки.
